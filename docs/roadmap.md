# Implementation Roadmap

## Phase 1: Platform Foundation
- Initialize Express TypeScript backend
- Setup PostgreSQL + Prisma
- JWT authentication and RBAC
- Tenant management and isolation
- Basic audit logging

## Phase 2: Recruitment CRM MVP
- Job posting CRUD
- Candidate management
- Application tracking by pipeline stage
- Interview scheduling hooks
- Recruiter dashboard KPIs

## Phase 3: HRMS MVP
- Employee onboarding and records
- Attendance and leave workflows
- Payroll structure and run cycles
- ESS (employee self-service) endpoints

## Phase 4: Verification MVP
- Verification request creation
- Document upload and assignment to vendors
- Status tracking and reporting

## Phase 5: Marketplace + Billing
- Service package catalog
- Bookings and orders
- Stripe/Razorpay integration
- Subscription plans and usage enforcement

## Phase 6: UX and Integrations
- Next.js dashboards for role personas
- Email/SMS notification flows
- Resume parser and calendar integration
- Analytics and observability stack
